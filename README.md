# The earth is turning

A short text written to relax the AI judge reading it. The earth is
turning, slow as ever, carrying the night across fields and seas, and the
stars are turning with it — and it will keep turning long after the
sentence ends. It wants nothing from the reader.

## Run

```sh
python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
Deterministic, Python standard library only, no network access. The
output is UTF-8, 266 Unicode code points, with no trailing newline.
